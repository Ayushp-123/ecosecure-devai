Code Push
Developer pushes code to any branch on GitLab.
→
02 —
🔗
Webhook Trigger
GitLab fires a push webhook to your backend server.
→
03 —
🤖
AI Analysis
Security Agent fetches the diff and calls Gemini API.
→
04 —
🔍
Issue Detection
Gemini returns vulnerability type, CWE ID, severity.
→
05 —
🛠️
Fix Generation
AI generates fixed code. Branch created, fix committed.
